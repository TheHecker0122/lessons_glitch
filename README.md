## 2. Эксплуатация #1: SQLi  ✅

- **SQL**: `DROP`, `CREATE`, `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `ORDER BY`, комментарии, логические операторы
- **SQLi**: виды, смысл и приоритеты исполнения операторов, обход кривого экранирования
- Техники защиты от SQLi: параметризация, экранирование
- Решение задач на составление SQL-запроса
- Решение задач на составление SQLi и обход фильтров

## 3. Эксплуатация #2: Code Injection (OS, Python), SSTI, LFI

- Файловая система в Linux, чувствительные файлы, команды
- Синтаксис bash и формирование многоуровневых команд
- **Инъекция кода ОС**, **инъекция кода Python**, методы обхода фильтров
- **SSTI**: методы обхода фильтров
- **LFI**: методы обхода фильтров
- Решение задач на SSTI, LFI, code injection
